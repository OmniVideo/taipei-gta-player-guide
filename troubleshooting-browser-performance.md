# Troubleshooting — browser performance

Aligned with homepage tips and [https://taipeigta.com/guides/mobile-performance](https://taipeigta.com/guides/mobile-performance).

## Symptom → first check

| What you see | First check | Next step |
| --- | --- | --- |
| Progress never finishes | Network; is the bar still moving? | Keep the tab foreground; if stuck, verify other sites load, then **Reload game** once |
| Menu OK, city black / broken | Graphics quality / WebGL support | Set quality to **Low**, retry; try another browser/device |
| City visible but stuttery | Device load | Close heavy apps/tabs; lower quality; watch FPS if enabled |
| Picture OK, input dead | Menus open? Wrong mode? | Close map/phone; tap play area; use the correct touch/key for current state |
| Progress odd after app switch | Tab suspended / reloaded | Return to the same page; keep game foreground for long sessions |
| Keys scroll the webpage | Focus on outer page | Click/tap inside the play canvas |
| Share link has no preview | Platform cache | Share the public page URL; preview art is themed illustration, not a live screenshot |

## Graphics presets

When checked on the site: quality options include **Auto / Low / Medium / High / Ultra (極致)** and optional **Show FPS**. The game itself suggests lowering quality when stuttering. Compare at the same spot after each change.

## Do not clear site data first

Clearing site data can wipe local progress. Prefer reload + Low quality first. Only clear storage if you accept that risk.

## Desktop extras

- Theater mode enlarges the embed; fullscreen depends on the browser.
- After leaving fullscreen, guides remain below the play area on the homepage.

## Still failing?

Note OS/device, browser name, quality preset, and whether you stuck on load, main menu, or after entering the city. That report is more useful than “it doesn’t work.”
