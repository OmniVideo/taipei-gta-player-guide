# Taipei GTA Player Guide

Keyboard notes, beginner steps, FAQ, scooter tips, map/mission overview, and browser troubleshooting for [Taipei GTA](https://taipeigta.com/) — a Taipei-themed **3D open-world game you play in the browser**. No install and no site registration required: open the homepage, select **Start game**, wait for resources to load, then explore.

This repository is maintained by the **Taipei GTA team**. It is documentation and player notes only. It does not host the game binary, call an API, or replace the in-game controls screen. Mission availability, rewards, and bindings follow the **current game version**.

**Not affiliated with Rockstar Games or the Grand Theft Auto series.** Taipei GTA is an independent browser game. Brand names that appear in scenery are fictional parodies per the site.

## How to use

1. Open [https://taipeigta.com/](https://taipeigta.com/) and select **Start game**. Wait until the in-game progress finishes — homepage UI ready ≠ city assets loaded.
2. Click inside the play area so the browser sends keyboard input to the game (otherwise WASD/Space may scroll the page).
3. Skim `beginner-guide.md` and `controls-cheat-sheet.md`, then practice a short walk and a short scooter ride before a long trip.
4. For missions and metro, use the in-game phone (**T**). For performance issues on phone or desktop, read `troubleshooting-browser-performance.md` before clearing site data.

## Product facts (from the live site)

- Browser play; keyboard · controller · touch; languages Traditional Chinese / English.
- Move with **W A S D**; enter/exit vehicle **F**; map **M**; in-game phone **T**; Space = jump on foot / handbrake while driving; pause **Esc**.
- Explore a creative Taipei-inspired city (e.g. Ximending, night markets, Xinyi / Taipei 101). Distances and roads follow the game map, not real-world GPS.
- Free play entry and guides on the homepage; first load downloads city/graphics resources (not an offline game).
- Progress stays in the browser storage for that origin/device/mode — share buttons share the page URL only, not saves.
