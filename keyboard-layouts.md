# Keyboard layouts by mode

Same physical keys can mean different things depending on whether you are on foot, driving, or looking at the map. This note summarizes the live-site behavior so you do not mix modes.

## Mode A — on foot

- `W A S D` — walk
- `Shift` — sprint
- `Space` — jump
- `E` — interact (when a prompt appears)
- `F` — enter vehicle when close
- `M` / `T` / `Esc` — map / phone / pause

## Mode B — driving

- `W` — throttle · `S` — brake / reverse · `A` `D` — steer
- `Space` — handbrake (drift practice later)
- `F` — exit
- `V` / `C` — camera / look behind
- `H` / `Q` — horn / radio
- Map and phone keys still work once the menus are open

## Mode C — map open (`M`)

While the map is open, movement keys pan the map instead of moving your character:

| Purpose | Input |
| --- | --- |
| Open map | `M` (focus the game first) |
| Pan | `W A S D` or drag |
| Zoom | `Q` / `E` or mouse wheel |
| Set navigation | Click a location |
| Recenter on self | `C` or “return to me” |
| Close | `Esc` or the map close button |

After closing the map, `W A S D` again move the character or vehicle.

## Mode D — mission start

- On the map, mission starts may show a marker (site guide: 「任」).
- Walk into the glowing area and press `E` (touch: Interact).
- Important: with the map open, `E` is zoom — close the map/phone first, then interact.

## Controllers

Use the in-game **Controller** tab. Do not treat this keyboard list as a pad mapping; labels differ by device.
