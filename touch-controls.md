# Touch controls (phone / tablet)

From the site touch guide and [mobile performance guide](https://taipeigta.com/guides/mobile-performance). No APK from this site — use a normal browser on [https://taipeigta.com/](https://taipeigta.com/).

## Before you start

1. Prefer the device browser over an in-app webview if loading fails.
2. Rotate to **landscape** before or during load.
3. Select **Start game**, wait for resource progress (don’t spam reload).
4. Open main menu → **Controls → Touch**, test a short walk, then a vehicle.

## On-screen actions

| State | Action | Touch |
| --- | --- | --- |
| On foot | Move / look | Left stick · swipe right side to look |
| On foot | Sprint / jump / interact | Stick fully / Sprint · Jump · Interact buttons |
| Any | Enter / exit | Approach vehicle → Enter/Exit |
| Driving | Go / stop / reverse | Accelerator & brake pedals; left stick steers |
| Driving | Handbrake / camera | Handbrake · Camera buttons — practice slowly |
| Menus | Missions / map / pause | Phone · Map · Pause buttons |

If the stick steers but you don’t move forward while “in” a vehicle, you likely need the **throttle pedal**, not only forward stick.

## Comfort settings

In-game settings may include **HUD size** and **look sensitivity**. Change one thing at a time. Theater mode on the homepage enlarges the play area when the panel feels tiny; it is not the same as lowering graphics quality.
