# Controls cheat sheet

Source: keyboard / mouse page on [Taipei GTA](https://taipeigta.com/). Click the play area first so keys go to the game. If bindings change after an update, trust the in-game **Controls** screen.

## Remember these first

| Action | Key |
| --- | --- |
| Move / drive | `W` `A` `S` `D` |
| Enter / exit vehicle | `F` |
| Map & navigation | `M` |
| In-game phone | `T` |
| Jump (on foot) / Handbrake (driving) | `Space` |
| Pause | `Esc` |

## On foot & general

| Action | Key | Notes |
| --- | --- | --- |
| Move | `W` `A` `S` `D` | Explore and approach interactables |
| Look | Mouse | Aim view before sprinting into traffic |
| Sprint | `Shift` | On foot only |
| Jump | `Space` | On foot |
| Interact | `E` | Follow on-screen prompts (mission markers, etc.) |
| Switch weapon / Reload | `Tab` / `R` | Follow in-game instructions |
| Map / Phone / Pause | `M` / `T` / `Esc` | Navigation, missions, pause menu |

## Scooters & cars

| Action | Key | Tip |
| --- | --- | --- |
| Enter / Exit | `F` | Stand close to the vehicle |
| Accelerate | `W` | Short presses first |
| Brake / Reverse | `S` | Slow before turns; release when stopped unless you want reverse |
| Steer | `A` / `D` | Look ahead early |
| Handbrake / Drift | `Space` | Driving only — not the same as jump |
| Horn / Radio | `H` / `Q` | Audio while driving |
| Camera / Look behind | `V` / `C` | Change view; check rear |

## Esc & fullscreen

The browser may consume `Esc` to leave fullscreen or unlock the pointer before the game sees it. If nothing happens, click the play area again and use the in-game pause menu.
